## Notae v0.5.0

Notae is now a native Android app built with Jetpack Compose, over the same Rust core. The library, search, favorites and sets work as before, and the app adds reordering, text notes in sets and a two-pane layout on wide screens.

**This is a new app id, `com.c2yz.notae`.** It installs beside v0.3.0 or v0.4.0 instead of updating them, and starts with an empty library.

### Moving from v0.3.0 or v0.4.0
1. In the old app, open Settings and tap **Export sets**.
2. Install v0.5.0, tap **Import from a previous Notae** on its first screen and pick the exported file. You can also use **Import sets** in Settings later.
3. Choose the score folder again; the PDFs are rescanned.

Only favorites and sets move across. Edited details (number, title, composer, tags) and the Recent list are not carried over. Keep the old app installed until you have checked the new one.

### What's new
- **Two panes on wide screens.** At 840 dp and wider, the details open beside the library.
- **Sets:**
  - Reorder mode: drag a row, or use the arrow buttons or the keyboard.
  - Text notes between pieces.
  - The piece you opened last is marked "Just opened".
- **Keyboard:**
  - Ctrl K opens Search from the library and the details.
  - Escape closes the innermost sheet or dialog.
  - Back closes Search and Settings before the details.
- **Language:** the app follows the per-app language setting (English or Polish) on every Android version.

### Removed
- The desktop indexer and its Tesseract OCR, and the import of its sidecar files. Scanned PDFs without a text layer are found by file name only (number and title).

### Build and release
- The app is built with Gradle and cargo-ndk, and its native code is 16 KB aligned. The core is a library called through UniFFI, and no `unsafe` code remains.
- GitHub CI runs the Rust gates, the Gradle gates (lint, unit and screenshot tests, the release build) and an emulator smoke test.
- This release was built, signed and verified by `release.yml` from the tag.

### Verification
- **Gates:** all gates pass with `scripts/check.sh full`: 370 Rust tests, 281 Android tests and 89.9% line coverage.
- **Emulator:** a parity check was run on an API 35 tablet emulator against v0.3.0. 124 of 132 checklist lines pass; the rest need a real device or are no longer parity targets. Screenshots are in `docs/compose-parity/`.
- **Large library:**
  - **Snapshot:** for 2,000 rows it takes about 3 ms on a desktop host.
  - **Emulator:** an earlier build measured 20–22 ms there, running under arm64 translation.
- **Not yet verified on the Galaxy Tab S10 FE+.** This covers the large-library frame time, TalkBack and the microphone search.

### Install
Download `notae-0.5.0-arm64.apk` and its `.sha256`, and verify the signature as described in the README's **Install** section. The signing certificate is the same as for every earlier release.
