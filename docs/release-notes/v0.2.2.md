## Notae v0.2.2

Notae keeps a personal sheet-music library organized: index PDFs on a Linux desktop with `notae-index`, then browse and search them on an Android tablet or phone. This is a small follow-up to v0.2.1: it fixes Polish `ł`/`Ł` search (#35) and the import review layout (#34), makes the library grid usable on a phone, and replaces the long-press menu and the Info icon with a visible ⋮ button.

**Please test on your own device.** Everything below was verified with host tests (including the generated UI rendered by Slint's software renderer) and in CI. None of it has been run on a phone or on an emulator, and none of it has been accepted on the Galaxy Tab S10 FE+; see "Known limitations" and report findings on the issues.

### Search
- **#35 Polish `ł`/`Ł`:** typing `palka`, `Galuszka`, `czesci stale`, `zmartwychwstal` or `lodz` now finds `Pałka`, `Gałuszka`, `części stałe`, `zmartwychwstał` and `Łódź` in titles, composers, tags and lyrics, in every Search scope. Queries typed with the diacritics keep working, and titles and lyric snippets are still shown in their original spelling. `l` and `ł` are one letter for search, so `lodz` also finds a score titled `Lodz`.
- **Index schema version 2 (forward-only):** the search index folds `ł`/`Ł` as it is written, so an existing index is migrated in place the first time this build opens it. After that, **older builds (v0.2.1 and earlier) refuse the index** with a version error. The sidecar format is unchanged (still schema 2).

### Library
- **Phone-friendly grid:** on a phone the grid shows two outlined cards per row (three on a wider screen) with a thumbnail, title and number · composer, instead of one tile as large as the whole screen. Windows 600 px wide or more, such as the Galaxy Tab S10 FE+, keep their layout.
- **⋮ More actions:** every card and list row, including Recent, ends with a visible 48 px ⋮ button that opens a bottom sheet with **Open score**, **Score details** and **Edit details**. It replaces the Info icon (#26) and the long-press menu, which is removed. Tapping a card still opens the PDF. A visible button is also an action TalkBack users can reach, which the long press never was.

### Import review
- **#34 Spacing:** the entries of the "Review desktop import" sheet are separated by a gap, and a divider separates the "On device" and "From desktop" values inside each entry. The layout is covered by tests for the divider and the dark theme.

### Documentation
- **On-device OCR (#28) is accepted in ADR 0001 as a decision only.** The ADR describes a manual, foreground OCR step started from Settings. **OCR is not implemented in this release**; nothing runs OCR on Android, and image-only PDFs still rely on desktop OCR and the sidecar, as before.

### Known limitations / not yet verified
- **The ⋮ button, the action sheet and the phone grid are verified through host tests and software renders only.** They have not been run on a phone or an Android emulator, and not on the tablet. Please check tap targets, the sheet position and the grid at several widths on real hardware.
- **TalkBack on the tablet is for the maintainer to verify.** The ⋮ button is meant to give TalkBack users a route to the item actions; whether it reads and operates well with TalkBack on the Galaxy Tab S10 FE+ is not yet confirmed.
- **#34 and #35 stay open** until the maintainer has checked the import review layout and the Polish search on the tablet.
- **On-device OCR (#28) is not implemented** (see Documentation above).
- **Index schema 2 is one-way.** Back up the index (or be ready to rescan) before installing if you may want to go back to v0.2.1.

### Install
The signed arm64 APK (`notae-0.2.2-arm64.apk`) and its `.sha256` are attached to this release when published by the Release workflow. It is signed with the same dedicated Notae release key as v0.2.0 and v0.2.1, so it installs over them and keeps your index (migrated to schema 2 on first open), preferences and folder grant. An install made from a debug build must be uninstalled first, which deletes the app's private data; the PDFs are untouched and the index is rebuilt by scanning again.
