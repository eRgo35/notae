## Notae v0.4.0

A maintenance release with **no app changes**: the APK is functionally v0.3.0, rebuilt and signed with the same release key, so it installs over v0.3.0 and v0.2.x and keeps your index, preferences and folder grant. The next app is v0.5.0, the native Android (Compose) rewrite.

### What changed
- **Releases are built on the maintainer's PC** with `scripts/release.sh`, from the tag in a clean worktree, after every quality gate passes. It checks the APK's version and that it is signed with the pinned release certificate before publishing.
- **Quality gates run locally** with `scripts/check.sh` (`fast` or `full`), with an opt-in pre-push hook. GitHub CI runs a light check (formatting, Clippy, tests).
- **Docs:** a new [`ROADMAP.md`](https://github.com/eRgo35/notae/blob/main/ROADMAP.md) and [`GLOSSARY.md`](https://github.com/eRgo35/notae/blob/main/GLOSSARY.md), a development-workflow section in `CONTRIBUTING.md`, and updated build and release guides.
- **Public repository:** the history was cleaned of local paths and personal data and re-signed. Commit hashes changed and the release tags moved; earlier release APKs are unchanged.

### Verification
- All nine quality gates pass with `scripts/check.sh full`, and again inside the release run.
- No app code changed since v0.3.0, so the v0.3.0 limitations still apply: it is verified on the tablet emulator, **not yet on the Galaxy Tab S10 FE+**.

### Install
Download `notae-0.4.0-arm64.apk` and its `.sha256`, and verify the signature as described in the README's **Install** section. The signing certificate is the same as for v0.2.x and v0.3.0.
