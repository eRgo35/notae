## Notae v0.9.2

Notae 0.9.2 follows the schola's new folder layout and fixes bugs found in a review of the app. It updates v0.9.1 in place (same app id, `com.c2yz.notae`) and keeps your library, favorites, sets, notes and drawings.

### Changed
- **Skipped folders.** `sources/`, `skany/` (original scans) and `inne/` (other material) in the library root are not listed as scores, in the app and in the PC sidecar tool. A ZIP import does not unpack them, so the scans take no space on the tablet.

### Fixed
- **Polish names in a ZIP from Windows.** A ZIP made on Polish Windows keeps names like „Błogosławiona” on a device instead of turning them into „B�ogos�awiona”.
- **ZIP folders written with `\`.** Such a ZIP (from Windows PowerShell, for example) no longer stops the whole library from opening.
- **Two ZIPs at once.** A ZIP shared while another one is unpacking is ignored, instead of starting a second import into the same folder.
- **Editing a score's details.** Saving marks only the fields you changed as yours. The others, such as a composer from the PC sidecar, still update when the sidecar changes.
- **Saving after a power cut.** Favorites, sets, notes and preferences reach the disk before they replace the old file, so a power cut cannot leave an empty one.
- **Viewer.** A score still opening when you move on (Next, Back) is closed, and the viewer keeps its page when the app is recreated, for example when dark mode turns on.
- **Scale.** A scale outside 25–400 % is kept within that range, so it survives a restart.
- **PC sidecar tool.** A catalogue number used by two scores is an error, and old thumbnails are removed only after `library.json` is written.

### Dependencies
- Rust dependencies, Android Gradle Plugin 9.5.3, Navigation 3 1.2.2, Robolectric 4.18.1, Roborazzi 1.79.0 and Gradle 9.9.3.

### Verification
- **Gates:** `scripts/check.sh full` and GitHub CI (Rust and Gradle gates: lint, unit and screenshot tests, the release build). New tests cover the skipped folders in a ZIP, `\` in ZIP names, the fields marked as edited and a catalogue number used twice. The sidecar tool run on the schola library writes the same `library.json` as before, without the scans.
- **Not tested on a physical tablet.** The Polish Windows ZIP names follow Android's own ZIP decoding, which the unit tests (on the PC's Java) cannot show.
