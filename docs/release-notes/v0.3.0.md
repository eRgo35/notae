## Notae v0.3.0

Notae keeps a personal sheet-music library organized on an Android tablet. This release adds a Polish interface with a language switch, **Favorites**, and **Sets** for preparing the music for each Mass or service. It is the last release built with the current Slint interface: the next app, v0.5.0, is a rewrite with a native Android interface under a new package name, and **Export sets** in this release is how favorites and sets move to it.

**Please test on your own device.** Everything below was verified with host tests, in CI, and on an Android tablet emulator (API 35, x86_64 build). None of it has been accepted on the Galaxy Tab S10 FE+; see "Known limitations".

### Language
- **Polish UI:** every screen, dialog and status message is translated into Polish.
- **Language in Settings:** **System default**, **English** or **Polski**. The choice also follows Android's per-app language setting.

### Favorites
- **Add to favorites** in a piece's ⋮ sheet stars it; **Remove from favorites** unstars it.
- The new **Favorites** section lists starred pieces, newest first. A favorite whose PDF is no longer in the library is hidden until it comes back.

### Sets
- **Sections:** the new **Sets** section lists your sets. Create one with a name, an optional date (`YYYY-MM-DD`) and optional notes; edit or delete it later. Deleting asks for confirmation.
- **Inside a set,** pieces show in the set's own order with their position numbers. Add pieces with **Add**, or with **Add to set…** in a piece's ⋮ sheet, and remove them with **Remove from set**. The same piece may appear more than once, and each copy keeps its own place.
- **Missing pieces:** a piece that is no longer in the library keeps its place in a set, shown as "Missing from library". When a rescan finds a replaced PDF at the same path, its favorite and set entries are re-linked to it.
- **Storage:** favorites and sets live in the app's private storage, never in the library folder.

### Export
- **Export sets** in Settings saves favorites and all sets to one JSON file through Android's save dialog. Keep this file: v0.5.0 imports it. There is no import in v0.3.0.

### Dependencies
- `sha2` 0.11, `pollster` 1.0, `serde_json` and the GitHub Actions group updated; `pulldown-cmark` 0.13.5 for RUSTSEC-2026-0414.

### Known limitations / not yet verified
- **Not run on the tablet.** The new screens were checked on the tablet emulator only. Please check them, and TalkBack, on real hardware.
- **Polish wording** awaits the maintainer's review; report anything that reads oddly.
- **Reordering pieces inside a set is not available yet.** It arrives in v0.5.0.
- **"New set" from the Add-to-set sheet** creates the set and adds the piece, but stays on the current screen.
- **Repeats** of a piece already in a set can only be added from the set's **Add** picker.
- **Set dates** are plain `YYYY-MM-DD` text, treated as UTC.
- **On-device OCR (#28) is not implemented.**

### Install
The signed arm64 APK (`notae-0.3.0-arm64.apk`) and its `.sha256` are attached to this release when published by the Release workflow. It is signed with the same dedicated Notae release key as v0.2.x, so it installs over them and keeps your index, preferences and folder grant.
