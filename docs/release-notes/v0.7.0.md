## Notae v0.7.0

Notae now slides between screens instead of fading, shows each set as a stack of its scores, lets you write notes on scores and in sets, and lets you share a set with other people.

It updates v0.6.1 in place (same app id, `com.c2yz.notae`) and keeps your library, favorites and sets.

> **Before you update:** this version saves sets in a new file format. Older files are read and upgraded, but **you cannot go back to 0.6.x** afterwards: 0.6.x cannot read the new file. Use **Export sets** first if you want a backup.

### What's new
- **Sections slide.** Switching sections slides in the order of the side rail or bottom bar. Deeper screens (a set, the details, Settings) slide in from the right without fading over the screen underneath, which stays still. Back, the back arrow and the back gesture run that in reverse: the screen leaves to the right and the one below comes back from the left. Search fades in, dropping a little from the top, and fades out rising, whether you close it with its arrow, the Back key or the back gesture. The tablet's side panel slides in and out, and the library moves with it, taking its new number of columns once; the chips that replace the hidden panel fade out before the panel comes, and fade in after it goes. Only the content moves: the side rail or bottom bar and the top bars stay in place, and what differs between the two screens' bars fades through, the old bar fading out before the new one fades in. On a tablet in landscape only the details pane slides in beside the list, which takes its new width at once and moves only with the side panel. Setup and loading still fade.
- **Set artwork is a stack of previews.** A set shows the first page of its first scores, stacked, in paper proportions at every size. Small tiles show a mini stack. A set with only text notes shows a note page, and an empty set shows an outline.
- **Score notes.** Write a note on a score; it is shown in the details wherever the score opens. To remove a score note or a set note, clear its text and save.
- **Set notes.** Write a note on one occurrence of a score in a set. It is shown in the details when you open the score from that set, and rows with a set note are marked. A score that is in a set twice has a note for each.
- **Back returns to the library.** Back from any other section (Sets, Favorites, Recent, a composer) goes to All scores first; Back on All scores leaves the app as before.
- **The set's "Notes" field is now "Description"** (occasion, time, cantor). Nothing else about it changed.
- **Share a set.** Tap the share icon in the set's toolbar, or **Share** in the set's ⋮ menu, then choose **Share set** or **Share set with notes**. Notae sends a `.notae-set` file and a readable list through Android's share sheet. It never sends PDFs or your personal score notes.
- **Receive a set.** Open the file in Notae (Open with, Share to, or **Import sets** in Settings). A review shows how many scores matched your library and which did not. Scores that did not match stay in the set as placeholders showing the sender's number and title, and keep them when you share the set on. Matching by number and title happens once, at import; afterwards a placeholder links up only when a scan finds the same file (the same content or the same path), and then shows your library's number and title. If you already have that set, the review names it; choose **Replace**, which keeps your set notes where the file has none, or **Keep both**.
- **Export sets** now includes your score notes. Exports made by earlier versions still import.
- Everything follows Android's **Remove animations** setting.

### Known limitations
- Notae still opens scores in another app; its own viewer is planned for 0.8.0.
- You cannot downgrade to 0.6.x after opening this version (see above).

### Verification
- **Gates:** GitHub CI runs the Rust gates and the Gradle gates (lint, unit and screenshot tests, the release build). New tests cover the notes and the sets file format, building and receiving a shared set, and the new motion. The screenshot goldens were re-recorded for the set artwork and the notes.
- **Not verified on a device or an emulator.** Screenshot tests cannot show motion, and sharing between two devices has not been tried. Please report anything that looks or feels wrong.
- **Not yet verified on the Galaxy Tab S10 FE+**, as for v0.6.1.

### Install
Download `notae-0.7.0-arm64.apk` and its `.sha256`, and verify the signature as described in the README's **Install** section. The signing certificate is the same as for every earlier release.
