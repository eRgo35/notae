## Notae v0.7.1

Notae now links its privacy policy and lists the open-source licenses of everything it includes, and it is on Google Play.

The GitHub APK is signed with the same key as before, so it updates a GitHub install of 0.7.0 in place.

### What's new
- **Privacy policy.** Settings, under About Notae, opens the privacy policy at <https://notae.c2yz.com/privacy/> in your browser. Notae itself still has no network access; the browser fetches the page.
- **Open-source licenses.** Settings, under About Notae, shows Notae's license and the licenses of the Rust crates and Android libraries it includes, with where to get the source of the MPL-2.0 crates.
- **Google Play.** Notae is in internal testing on Google Play. Google Play signs the app with its own key, so the Play app and the GitHub APK do not update each other. To switch between them, use **Export sets** in Settings, uninstall Notae, install the other one, then tap **Import from a previous Notae** and pick the exported file. Uninstalling deletes the folder access, the index, details you edited in the app and the Recent list, never your PDFs.

### Known limitations
- Notae still opens scores in another app; its own viewer is planned for 0.8.0.
- You cannot downgrade to 0.6.x after opening 0.7.0 or later.

### Verification
- **Gates:** GitHub CI runs the Rust gates and the Gradle gates (lint, unit and screenshot tests, the release build) and checks the license notices against `Cargo.lock`. New tests cover opening the privacy policy and the licenses screen; the Settings screenshot goldens were re-recorded.
- **Devices:** the Google Play build of 0.7.1, built from the same code, was installed and used on a Galaxy S25 FE and a Galaxy Tab S10 FE+.

### Install
Download `notae-0.7.1-arm64.apk` and its `.sha256`, and verify the signature as described in the README's **Install** section. The signing certificate is the same as for earlier releases:
