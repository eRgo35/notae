## Notae v0.7.1

Notae now links its privacy policy and lists the open-source licenses of everything it includes, and it is coming to Google Play.

The app id is still `com.c2yz.notae`, but this version is signed with a new key, so it does **not** update a GitHub install of 0.7.0 or earlier in place.

> **Before you update (GitHub APK users):** from 0.7.1, the APK on GitHub is the one Google Play signs, with Google Play's app signing key. Android will not update an app signed with a different key, so if you installed 0.7.0 or earlier from GitHub, do this once:
> 1. Use **Export sets** in Settings and keep the file outside the app. It holds your favorites, sets, set notes and score notes.
> 2. Uninstall Notae. This deletes the folder access, the index and the details you edited in the app (number, title, composer, tags) and the Recent list. Your PDFs are not touched.
> 3. Install 0.7.1.
> 4. On the first screen tap **Import from a previous Notae** and pick the exported file, then choose your score folder and scan again.
>
> After that, updates from GitHub and from Google Play install over each other in place.

### What's new
- **Privacy policy.** Settings, under About Notae, opens the privacy policy at <https://notae.c2yz.com/privacy/> in your browser. Notae itself still has no network access; the browser fetches the page.
- **Open-source licenses.** Settings, under About Notae, shows Notae's license and the licenses of the Rust crates and Android libraries it includes, with where to get the source of the MPL-2.0 crates.
- **Notae is coming to Google Play.** The GitHub APK and the Play app are the same app, signed with the same key, so you can switch between them without reinstalling.

### Known limitations
- Notae still opens scores in another app; its own viewer is planned for 0.8.0.
- Moving a GitHub install of 0.7.0 or earlier to 0.7.1 needs the one-time export, uninstall and import above; details you edited in the app and the Recent list are not carried over.
- You cannot downgrade to 0.6.x after opening 0.7.0 or later.

### Verification
- **Gates:** GitHub CI runs the Rust gates and the Gradle gates (lint, unit and screenshot tests, the release build) and checks the license notices against `Cargo.lock`. New tests cover opening the privacy policy and the licenses screen; the Settings screenshot goldens were re-recorded.
- **Not verified on a physical device yet.**

### Install
Download `notae-0.7.1-arm64.apk` and its `.sha256`, and verify the signature as described in the README's **Install** section. The signing certificate is **new**: Google Play's app signing certificate,

```text
C9:29:70:28:91:42:32:BD:DA:2B:CB:41:BF:AC:9F:34:07:1C:08:66:4F:BE:BD:1C:57:1B:9B:39:BD:66:D3:E8
```

not the one earlier releases were signed with.
