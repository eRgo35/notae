## Notae v0.10.0

Notae 0.10.0 fixes the rest of the bugs found in the 0.9.2 review and moves to the newer Android and UniFFI toolchain. It updates v0.9.2 in place (same app id, `com.c2yz.notae`) and keeps your library, favorites, sets, notes and drawings.

### Fixed
- **Changing the library folder during a scan.** The new scan waits for the old one to stop, so two scans never write the index at once, and the app does not wait for it meanwhile ([#61](https://github.com/eRgo35/notae/issues/61)).
- **A file that could not be read.** When your sets, favorites or notes file cannot be read (damaged, or written by a newer Notae), the next change no longer destroys it: it is kept beside the new one as `sets.json.corrupt` (or `favorites.json.corrupt`, `score-notes.json.corrupt`) ([#62](https://github.com/eRgo35/notae/issues/62)).
- **Exact titles with Polish capitals.** A search for „Święty Boże” puts the score with exactly that title first, also when the list is cut short ([#63](https://github.com/eRgo35/notae/issues/63)).
- **Very large libraries.** A rescan of a library with more than 32,766 PDFs removes deleted files instead of failing ([#64](https://github.com/eRgo35/notae/issues/64)).

### Dependencies
- Compose BOM 2026.11.01, which builds against Android 17 (compileSdk 37). The target SDK stays 36, so the app's behaviour on the device does not change.
- UniFFI 0.33.0. Its Kotlin bindings are generated Java 8 compatible, as Notae still runs on Android 8 and 8.1.

### Known limitations
- Zoomed pages in Scroll may still run short of memory on the tablet and show blank ([#65](https://github.com/eRgo35/notae/issues/65)). This has not been seen yet and needs a measurement on the device.

### Verification
- **Gates:** `scripts/check.sh full` and GitHub CI (Rust and Gradle gates: lint, unit and screenshot tests, the release build). New tests cover the new scan waiting for the old one, the kept `.corrupt` file, the exact Polish title with a limit and a library of 40,000 paths.
- **Not tested on a physical tablet** or on an Android 8 device.

### Install
